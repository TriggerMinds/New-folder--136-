# Kilo Code Startprompt

Lees volledig:

1. `PROJECTSPECIFICATIES.md`
2. `architectuur_blauwdruk.md`

Behandel beide bestanden als bindend projectcontract.

Harde regels:

- Genereer ieder bestand volledig.
- Gebruik geen placeholders, TODO's, pseudocode of ingekorte code.
- Gebruik geen mocks of simulaties.
- Introduceer geen zware infrastructuur zonder expliciete opdracht.
- DeepSeek-uitval mag ingestie nooit blokkeren.
- Iedere databasewijziging vereist een Alembic-migratie.
- Behoud bestaande werkende functionaliteit.

Wacht na het lezen op het eerste concrete implementatiedoel.
